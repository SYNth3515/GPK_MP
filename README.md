A multiplayer/coop project for Age Of Pirates 2: City of Abandoned Ships | Мультиплеерный/кооперативный проект для Корсары: Город Потерянных Кораблей

Необходимая версия игры 1.3.2 AT (не ATR, т.к. Open Storm Engine 2.9 не поддерживает мультиплеерные функции). В дальнейшем рассматривается возможность переезда на новый движок с компиляцией для него сетевых библиотек.

Пока удалось реанимировать только мультиплеер как в корсарах 3, в планах сделать полноценный кооператив где другие игроки выступают в роли офицера/компаньона по функционалу как дубликат игрока (диалоги ведутся с хостом при инициации от других пользователей).
