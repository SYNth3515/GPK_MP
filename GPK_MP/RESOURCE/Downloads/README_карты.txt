КАК ДОБАВИТЬ СВОЮ КАРТУ В СЕТЕВУЮ ИГРУ
=====================================

Карты лежат в папке RESOURCE\Downloads. Одна карта - одна папка.
Сухопутная карта (land) идёт в режимы на суше (дуэль, TDM), морская (sea) - остров в морских режимах.
Карту достаточно положить только хосту: клиент, у которого её нет, скачает её при подключении
(в окне "Загрузка ресурсов"). В списке карт они появляются через кнопку "Загрузки" в создании игры.


1. ПАПКА
--------
RESOURCE\Downloads\<ИмяКарты>\
  Имя папки: только латиница, цифры, _ и -, до 24 знаков (например Tavern09, My_Fort-2).
  Все файлы карты лежат прямо в этой папке, без подпапок:
    *.gm        - модели (сама локация/остров, локаторы, окна, отражение, дно...)
    *.col       - освещение моделей (TAVERN09_DAY11.COL и т.п.), если есть
    *.ptc       - патч ходьбы персонажей (для land)
    *.grs       - трава острова (для sea), если есть
    *.tga.tx    - ВСЕ текстуры, которые используют модели карты
    map.ini     - описание карты (см. ниже)
  Клиентам отправляются только файлы .gm .col .tx .ptc .grs .ini .txt .tga,
  имена файлов только латиницей, до 1000 файлов, каждый не больше 64 МБ.

  ВАЖНО про текстуры: если у карты своя папка, игра ищет текстуры ТОЛЬКО в ней и не берёт
  их из RESOURCE\Textures. Если текстуры не хватает, объект будет белым или чёрным.
  Это касается и моделей игры, которые карта подключает (например фон за окном
  models.always.back=..\..\models\Locations\Inside\inside_back): их текстуры тоже нужны в папке карты.
  Недостающие текстуры из игры скопирует инструмент (пункт 3).


2. map.ini
----------
Кодировка Windows-1251 (обычный Блокнот, "ANSI"). Пример:

  [map]
  name=Таверна форта Оранж
  type=land
  count=4
  a1=models.always.tavern=Tavern09
  a2=models.always.locators=Tavern09_locators
  a3=models.day.charactersPatch=Tavern09_patch
  a4=models.night.charactersPatch=Tavern09_patch

  name   - название в списке карт (можно по-русски)
  type   - land (суша) или sea (остров)
  count  - сколько строк aN ниже. Должны быть ВСЕ строки a1..aN, иначе карта не загрузится.
  aN     - атрибут локации/острова в виде путь=значение, как в скриптах одиночной игры
           (PROGRAM\Locations\init\*.c для суши, PROGRAM\Islands\islands_init.c для моря),
           только без "Locations[n]." / "Islands[n]." в начале.
  Пути к моделям пишутся без .gm, относительно папки карты. Модель самой игры можно взять так:
  ..\..\models\Locations\Inside\inside_back

  Сухопутная карта, что обычно нужно:
    models.always.<любое имя>=<модель>      - модели локации (можно несколько)
    models.always.locators=<модель локаторов> - точки появления/перехода (обязательно)
    models.day.charactersPatch / models.night.charactersPatch=<патч .ptc без расширения>
    models.always.window=<модель окон>, models.always.window.tech=LocationWindows, models.always.window.level=50
    environment.weather=true, environment.sea=false
    type=tavern / house / ... (тип локации, влияет на освещение), lockWeather=Inside (для помещений)
    reload.l1.name=<локатор двери>, reload.l1.emerge=<локатор>  - двери (в сетевой игре они закрыты)
    image=loading\inside\tavern.tga - картинка загрузки

  Морская карта:
    model=<остров>, refl_model=<отражение острова>, locators=<локаторы острова>    (обязательно)
    jungle.patch=<.grs без расширения>, jungle.texture=junglesprites, jungle.scale=10 - трава
    reload.l1.label / name / go / emerge / radius - бухты (как в islands_init.c)

  Строки id, index и filespath.* игра ставит сама, их писать не нужно.


3. ИНСТРУМЕНТ ПРОВЕРКИ: map_check.bat
------------------------------------
Лежит рядом с этим файлом. Запуск двойным щелчком - проверка всех карт.
Из командной строки (в папке RESOURCE\Downloads):

  map_check.bat                 - проверить все карты
  map_check.bat MyMap           - проверить карту MyMap
  map_check.bat MyMap -Fix      - проверить и скопировать в папку карты недостающие текстуры
                                  из RESOURCE\Textures (по именам из её моделей .gm)
  map_check.bat MyMap -New land - создать папку и шаблон map.ini для суши (или -New sea для острова)

Что проверяется: имя папки, все строки map.ini (name, type, count, a1..aN), что модели из map.ini
есть на диске, что есть локаторы, какие файлы не уйдут клиентам, размер, и что все текстуры
моделей лежат в папке карты. В конце по каждой карте пишется OK или число ошибок.


4. ПОРЯДОК
----------
  1) Создай папку: map_check.bat MyMap -New land (или -New sea).
  2) Скопируй в неё модели .gm, .col, патч .ptc / траву .grs и свои текстуры .tga.tx.
  3) Поправь map.ini: имена моделей, локаторов, дверей; name - как карта будет называться.
  4) map_check.bat MyMap -Fix - докопирует текстуры игры, которых не хватает.
  5) map_check.bat MyMap - должно быть OK.
  6) В игре: Сетевая игра -> Создать -> "Загрузки" -> выбрать карту.

Чужие карты (модели других авторов) не выкладывай в общий доступ без согласия автора.
